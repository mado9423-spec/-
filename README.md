# سَنَد · مسار الاستيراد

تطبيق مرافق للمستورد الليبي بعد **القرار 449 لسنة 2026**: رحلة واحدة واضحة من فتح الاعتماد إلى الإفراج الجمركي، تجمع بوابات **FCMS** (المصرف المركزي) و**ACI** (الجمارك) و**PTS** (شبكة ليبيا للتجارة) التي لا رابط بينها اليوم من منظور المستورد.

> **نموذج تفاعلي تجريبي.** كل الأسماء والأرقام أمثلة، ولا يرتبط بأي جهة رسمية. لم نجد واجهات برمجية عامة للبوابات، لذلك التطبيق «مرافق» يجهّز البيانات ويتحقق منها ويتتبع المتطلبات، ولا يرسل شيئًا إلى الجهات الرسمية.

- **التقرير البحثي الكامل:** [`docs/research-ar.md`](docs/research-ar.md) (القرار 449، المنظومات الثلاث، متطلبات المصارف، المنافسون، الفجوات، مصادر وتعارضاتها)
- **التطبيق:** [`app/index.html`](app/index.html) ملف واحد يعمل بلا خادم، ويُثبَّت كتطبيق (PWA)

## أهم نتيجتين بحثيتين

1. القرار 449 صادر عن **وزارة الاقتصاد والتجارة** (6 سبتمبر 2026، يسري من 30 سبتمبر)، وليس عن المصرف المركزي. والقناة المصرفية لا تقتصر على الاعتماد المستندي، فتشمل **التحويل المباشر** (حتى 100 ألف$ وفق تقارير).
2. لم نجد أي تطبيق جوال رسمي لإدخال البيانات الجمركية أو معاملات الاستيراد. بوابات PTS وACI وFCMS تعمل عبر المتصفح، ولا تعرض شروط التسجيل بوضوح ولا تتتبع «ماذا بعد؟».

## ماذا يفعل التطبيق

| الميزة | الوصف |
|---|---|
| **رحلة الاستيراد** | ست بوابات لكل شحنة: التمويل، المستندات، ACI، الشحن والوصول، الإفراج، التسوية، مع «الخطوة التالية» دائمًا |
| **محرك الامتثال** | يكشف ما سيمنع الإفراج قبل أن يحدث (مثل إثبات القيمة الفعلية في القرار 449) |
| **مُنسّق ACI** | يطابق حقول ACI الرسمية ويفحص IMO وHS وأرقام الحاويات (ISO 6346) والأوزان وتطابق القيمة مع الاعتماد، ويولّد حزمة نسخ ودعوة للمورد |
| **موافقة المستورد** | الخطوة التي يؤديها المستورد داخل ACI، مع فحوص اتساق قبل القرار |
| **مرشد القناة** | اعتماد أم تحويل مباشر أم نشاط فردي، بحسب القيمة والصفة، مع كل قاعدة موسومة بدرجة التأكد |
| **طلب اعتماد جديد** | معالج من ثلاث خطوات (حقول من لوحة سَنَد الأصلية) بحسابات الغطاء والانحراف والاستحقاق وتأكيد بالسحب |
| **مطابقة المستندات** | الفاتورة مقابل شهادة التفتيش كما يفعل المصرف |
| **قراءة إشعار البوابة** | الصق بريد ACI فتتحدث الحالة ورقم ACI محليًا |
| **رادار المواعيد** | مواعيد القرارين 449 و465 وموعد اعتماد ACI (قبل التحميل بـ 48 ساعة) |
| **المركز** | ملخص القرار، خريطة المنظومات، أسئلة شائعة بمصادرها ودرجات تأكدها |

التصميم عربي أولًا (RTL)، داكن وفاتح، يعمل بلا إنترنت بعد أول تحميل، ويحافظ على هوية اللوحة الأصلية (Readex Pro وIBM Plex Sans Arabic والبطاقات الزجاجية الباستيلية) مع لمسة ذهبية.

## التشغيل

```bash
node scripts/build.mjs      # يبني app/index.html من src/
npx serve app               # أو افتح app/index.html مباشرة
npm test                    # يبني ثم يشغّل اختبار المتصفح (يحتاج playwright)
```

لا توجد تبعيات تشغيل. `src/` يحتوي على `styles.css` وشيفرة JavaScript مرتبة بالأرقام و`shell.html`، ويجمعها سكربت البناء في ملف واحد.

## الهيكل

```
app/            ناتج البناء: index.html + manifest + service worker + أيقونات
src/styles.css  نظام التصميم (رموز الألوان، المكونات)
src/js/         00 أدوات · 10 أيقونات · 20 بيانات وFAQ · 30 المنطق (البوابات، فحص ACI، المطابقة)
                40 مكونات الواجهة · 50-55 الشاشات · 99 الإقلاع
docs/           التقرير البحثي
tests/smoke.mjs اختبار شامل للتدفقات الأساسية
```

## ما هو حقيقي وما هو محاكى

- **حقيقي ومحلي:** حسابات الاعتماد، فحوص ACI (IMO، HS، ISO 6346، الأوزان والطرود)، مطابقة المستندات، قراءة نص إشعار البوابة، مرشد القناة، رادار المواعيد، الحفظ على الجهاز.
- **محاكى:** حالات الجهات الرسمية (أزرار «محاكاة» في وضع العرض)، ورفع المستندات (يُحفظ اسم الملف فقط)، وسعر المركزي (من لوحة سَنَد الأصلية).
- **غير موجود بعد:** أي اتصال بـ FCMS أو ACI أو PTS أو المصارف.

## الخطوات التالية

1. **MVP عملي بلا واجهات رسمية:** صندوق بريد سَنَد تُحوَّل إليه رسائل ACI فتتحدث الحالات تلقائيًا (القارئ الحالي يعمل يدويًا على النص نفسه).
2. **اتفاق رسمي** مع شبكة ليبيا للتجارة والجمارك والمركزي لواجهات قراءة فقط.
3. **شراكة مصرفية** لتقديم طلب الاعتماد مباشرة وتبادل المستندات.
4. واجهة إنجليزية للموردين الأجانب، وتطبيقات أصلية عند الحاجة.

## تنبيه

القواعد منقولة من تقارير صحفية ومواقع رسمية حتى 7 أكتوبر 2026، ولم نصل إلى النص الرسمي للقرارين 449 و465 ولا لتعميمات المركزي الأخيرة. كل قاعدة في التطبيق موسومة بدرجة التأكد ومصدرها. هذا إرشاد وليس استشارة قانونية.
