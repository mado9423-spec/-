# دليل · Dalil

<p align="center"><img src="brand/mark-navy.svg" width="96" alt="شعار دليل: سفينة شراعية"></p>

تطبيق مرافق للمستورد الليبي بعد **القرار 449 لسنة 2026**: خطوة واضحة تلو الأخرى من فتح الاعتماد إلى الإفراج الجمركي، تجمع بوابات **FCMS** (المصرف المركزي) و**ACI** (الجمارك) و**PTS** (شبكة ليبيا للتجارة) التي لا رابط بينها من منظور المستورد. بالعربية والإنجليزية، يعمل على الهاتف، ولأي شخص يستعمله لأول مرة (شركة أو تاجر فردي).

> **نموذج تجريبي.** ليس جهة رسمية ولا يرتبط بأي بوابة حكومية. لم نجد واجهات برمجية عامة لهذه البوابات، لذلك التطبيق «مرافق»: يجهّز البيانات ويتحقق منها ويتتبع المتطلبات، ولا يرسل شيئًا إلى الجهات الرسمية.

## ماذا يفعل التطبيق

| الميزة | الوصف |
|---|---|
| **بداية مبسطة** | أربع خطوات: من أنت، ماذا تستورد، ما الذي لديك، ثم خطة شخصية. وخيار تجربة ببيانات تجريبية |
| **خطوة تالية واحدة** | الرئيسية تعرض ما عليك الآن وما ينتظر غيرك، ومسار الرحلة الكامل مطوي حتى تفتحه |
| **عربي وإنجليزي** | تبديل فوري للغة والاتجاه (RTL/LTR) والأرقام والتواريخ، والبيانات المخزنة محايدة اللغة |
| **محرك الامتثال** | ست بوابات لكل رحلة (التمويل، المستندات، ACI، الشحن، الإفراج، التسوية) ويكشف ما سيمنع الإفراج قبل أن يحدث |
| **مُنسّق ACI** | يطابق حقول ACI ويفحص IMO وHS وأرقام الحاويات (ISO 6346) والأوزان وتطابق القيمة مع الاعتماد، ويولّد حزمة نسخ ودعوة للمورد |
| **مرشد القناة** | اعتماد أم تحويل مباشر أم نشاط فردي، مع درجة تأكد لكل قاعدة |
| **مطابقة المستندات** | الفاتورة مقابل شهادة التفتيش كما يفعل المصرف |
| **قراءة إشعار البوابة** | الصق بريد ACI فتتحدث الحالة ورقم ACI |
| **رادار المواعيد** | مواعيد القرارين 449 و465 وACI (قبل التحميل بـ48 ساعة) ومستنداتك واعتماداتك |
| **حساب وفريق (اختياري)** | دخول بلا حساب ثم ربط Google أو البريد أو الهاتف، مزامنة بين الأجهزة، دعوة أعضاء بأدوار (مالك/مدير/عضو/مشاهد) عبر Firebase |

## التشغيل

```bash
npm ci                       # للاختبارات وSDK (التطبيق نفسه بلا تبعيات تشغيل)
npm run build                # يبني app/ من src/ ويولّد ترويسات الأمان
npm run serve                # معاينة محلية على :5173
```

بدون إعدادات Firebase يعمل التطبيق **محليًا**. للوضع السحابي: انسخ `firebase.config.example.json` إلى `firebase.config.json` بإعدادات مشروعك ثم أعد البناء (التفاصيل في [`docs/firebase-ar.md`](docs/firebase-ar.md)). الاسم الافتراضي يتغير بـ`BRAND=…` أو بتعديل `src/js/02-brand.js`.

## الاختبارات

| الأمر | ما يفعله |
|---|---|
| `npm test` | يبني ثم الوحدات (14) واختبار المتصفح (رحلتا البداية، اللغتان، CSP، الحقن، لا طلبات خارجية) |
| `npm run test:crawl` | نقر عشوائي مبذور يبحث عن انهيارات ونصوص عربية متسربة (`LANGV=en SEED=7`) |
| `npm run test:rules` | 18 اختبارًا لقواعد Firestore وStorage على المحاكيات (Java مطلوب) |
| `npm run test:e2e` | منشأة ودعوة وقبول ولحظي ومشاهد بمتصفحين على المحاكيات |
| `npm run test:functions` | منطق التذكيرات اليومية |
| `npm run test:all` | الكل |

> خلف وكيل HTTP: أزل `HTTPS_PROXY` عند تشغيل المحاكيات، فمحاكي Storage ينادي محاكي Firestore محليًا.
> متصفح الاختبار: إن كان Playwright مثبتًا عامًا فمرّر `PW_ROOT=<مجلد node_modules>`.

## النشر

الناتج ملفات ثابتة في `app/` ويصلح لأي استضافة ثابتة. `npm run build` يولّد `vercel.json` و`app/vercel.json` و`app/_headers` و`firebase.json` (ترويسات: CSP بتجزئات SHA-256، HSTS، `nosniff`…) من الصفحة نفسها، فلا تنحرف. الترويسات تشمل `noindex` لأنه نموذج تجريبي (أزلها عند الإطلاق العلني).

## ما هو حقيقي وما هو محاكى

- **حقيقي ومحلي:** حسابات الاعتماد، فحوص ACI (IMO، HS، ISO 6346، الأوزان والطرود)، مطابقة المستندات، قراءة نص إشعار البوابة، مرشد القناة، رادار المواعيد، الحفظ على الجهاز، التنقية والتحقق من البيانات.
- **حقيقي سحابيًا (مختبر على المحاكيات فقط):** الحساب والمزامنة والفريق والدعوات ورفع الملفات.
- **محاكى:** حالات الجهات الرسمية (أزرار «محاكاة» في وضع العرض)، وسعر المركزي (قيمة توضيحية).
- **غير موجود بعد:** أي اتصال بـ FCMS أو ACI أو PTS أو المصارف.

## تنبيه

القواعد منقولة من تقارير صحفية ومواقع رسمية حتى 7 أكتوبر 2026، ولم نصل إلى النص الرسمي للقرارين 449 و465 ولا لتعميمات المركزي الأخيرة. كل قاعدة في التطبيق موسومة بدرجة التأكد ومصدرها. هذا إرشاد وليس استشارة قانونية.
